## Release gate

Do not apply the migration or promote to production until Vercel linkage/environment verification is restored, development database tests pass, an isolated testing project is configured, and the authenticated preview passes the remaining acceptance checks. The current code is a reviewable implementation milestone, not the final Phase 1 deliverable.
