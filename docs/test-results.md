## Reproduce

Run from the repository root:

```sh
npm ci
npm test
npm run typecheck
npm run build
node scripts/check-standalone.cjs
node scripts/check-browser.cjs
```

The two application harnesses require an ignored `.env.testing` with `APP_ENV=testing`, testing Supabase URL/publishable key and `APP_ORIGIN=http://localhost:3100`. Browser checks also require `.env.testing-users.json` containing the isolated owner/manager/operator/support credential records generated by the demo setup. The browser suite mutates fictional test data only; do not point it at production. It checks the factory's demo marker before executing mutations. Failed runs may leave QA-prefixed fixtures for inspection.

Browser verification requires a separately installed Playwright test runtime and Chromium, not an application dependency. `PLAYWRIGHT_MODULE_PATH` may select an external Playwright installation; `CHROMIUM_EXECUTABLE_PATH` and `CHROMIUM_ARGS` may select a compatible browser. In a proxy-managed Node environment, supply the supported proxy environment configuration externally. The harness preserves browser security checks. Error output is restricted to the first line so request cookies are not printed.

The workspace used Playwright with a locally available Chromium 138 after the preferred browser CLI failed to start. The browser screenshots cover English desktop, Arabic desktop, Arabic mobile and reports. Browser runtimes, cookies, credentials and screenshots remain outside the source repository.
